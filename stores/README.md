# לוגואים של חנויות

כל קובץ כאן הוא הלוגו של חנות אחת, ומוצג כשנכנסים לאתר עם `?store=<שם>`.

## חשוב – שם הקובץ חייב להיות באותיות קטנות

השרת של GitHub Pages מבדיל בין אותיות גדולות לקטנות.
`OZ-CERAMICA.jpg` ו-`oz-ceramica.jpg` הם שני קבצים שונים מבחינתו,
ולכן קובץ עם אות גדולה פשוט לא ייטען (יוצג ריבוע ריק במקום הלוגו).

- שם הקובץ: אותיות קטנות בלבד, בלי רווחים (מקף במקום רווח).
- הפורמט: png / jpg / svg / avif / webp – כולם נתמכים.
- הכתובת לחנות: שם הקובץ בלי הסיומת, בסוף הכתובת.

לדוגמה – הקובץ `oz-ceramica.jpg` נטען מכל אחת מהכתובות האלה:
`https://catalog.mtibath.co.il/oz-ceramica`
`https://catalog.mtibath.co.il/?store=oz-ceramica`

## אחרי הוספת קובץ

צריך לעשות Commit ו-Push ל-GitHub, אחרת הקובץ קיים רק במחשב
והאתר החי לא יראה אותו. אחרי ה-Push לוקח דקה-שתיים עד שהאתר מתעדכן.
